Cómo funciona

  • Añadir un ticker: edita data/tickers.json en el repo y súbelo. La próxima ejecución del workflow trae 2 años de histórico para el nuevo símbolo automáticamente.
  • Actualización: un GitHub Action corre de lunes a viernes y hace commit de los precios nuevos en data/prices.json. También puedes ejecutarlo a mano desde la pestaña Actions.
  • Pedir análisis a Claude: pásale a Claude la URL cruda del archivo de datos (algo como https://raw.githubusercontent.com/TU_USUARIO/TU_REPO/main/data/prices.json) o descarga el archivo y súbelo al chat. Está en JSON simple: un arreglo de {fecha, cierre, volumen} por ticker.
  • Cambiar usuario/contraseña: corre python scripts/generate_credentials.py --username TU_USUARIO localmente (te pide la contraseña de forma oculta) y sube el data/auth.json resultante. La contraseña nunca se guarda en texto plano, solo su hash.
